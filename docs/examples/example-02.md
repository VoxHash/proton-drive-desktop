# Example: run the GUI

```bash
make user-install
proton-drive-linux
```

From the repo without installing:

```bash
python3 scripts/proton-drive-linux
```

After launch, Settings → Enable always-on folder uses official CLI download/upload. It is not a FUSE mount. Worker, last successful pass, files last pass, and last error update from the worker status file. Settings → Language lists System default, English, and ru / zh_CN / ar / it / pt / es / ko / ja.

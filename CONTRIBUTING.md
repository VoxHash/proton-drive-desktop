# Contributing

## Setup

```bash
python3 tests/test_cli.py
python3 -m proton_drive_linux
```

Requires Proton's official `proton-drive` CLI and a signed-in session.

## Pull requests

Use conventional commits (`feat`, `fix`, `docs`, `chore`). Keep diffs small.
